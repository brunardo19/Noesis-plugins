# Noesis-plugins
Format plugins for Rich Whitehouse's Noesis software

Plugins:

fmt_nxb: ".NXB": 3D model with textures and rigging. Used in Arc Systems Works game "Battle Fantasia -Revised-" for PC

fmt_dse: ".DSE": 3D model with textures. Used in Game Republic "Dragon Ball Kai: Ultimate Butoden" for Nintendo DS
